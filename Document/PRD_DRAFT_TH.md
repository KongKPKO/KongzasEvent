# Product Requirements Document (PRD) - EventQueueSocial

**สถานะ:** ร่าง (Draft) สำหรับนำไปพัฒนาต่อ
**อ้างอิงจาก:** ระบบ EventQueueSocial / EventWebQueue ปัจจุบัน

---

## Why this project exists
This project was inspired by real creator/cosplay event booth problems: long unmanaged queues, noisy LINE OpenChat queue calls, slow checkout, unclear stock status, payment mistakes, and difficult post-event tracking.

The goal is to build a lightweight queue + POS tool that helps creator booths manage customer flow, call queues clearly, reduce checkout friction, and give customers a trustworthy mobile queue experience without forcing them into chat groups.

---

## 1. Core Function (ฟังก์ชันหลักของระบบ)
ระบบจัดการคิวและระบบขายหน้าร้าน (POS) แบบครบวงจรผ่านเว็บแอปพลิเคชัน สำหรับบูธจัดแสดงสินค้า (เช่น บูธศิลปิน, คอสเพลย์) ในงานอีเวนต์ต่างๆ โดยมีจุดประสงค์เพื่อลดความแออัดหน้าบูธ ลูกค้าสามารถกดรับคิว ดูเมนูสินค้า และสั่งซื้อล่วงหน้าได้ผ่านสมาร์ทโฟนของตนเองโดยไม่ต้องติดตั้งแอปพลิเคชัน ในขณะที่ฝั่งเจ้าของบูธ/สตาฟ สามารถใช้ระบบจัดการคิวและคิดเงินได้อย่างรวดเร็ว

## 2. User Goals (เป้าหมายของผู้ใช้งาน)

ผู้ใช้งานระบบแบ่งออกเป็น 2 กลุ่มหลัก ซึ่งมีเป้าหมายดังนี้:

**กลุ่มที่ 1: ฝั่งร้านค้า (Booth Owner & Staff)**
*   **ลดความแออัดหน้าบูธ:** จัดการคิวได้อย่างเป็นระเบียบ ไม่เกะกะทางเดินในงาน
*   **ประหยัดเวลาและเพิ่มยอดขาย:** ใช้เวลาหน้าบูธไปกับการส่งมอบและพูดคุยได้มากขึ้น โดยมีระบบ POS ที่ช่วยคิดเงินและจัดการสต็อกให้รวดเร็ว
*   **ทำงานเป็นทีมได้:** สามารถแบ่งหน้าที่ระหว่างคนจัดคิวและคนคิดเงินได้ (Staff roles)

**กลุ่มที่ 2: ฝั่งลูกค้า (Attendee / Customer)**
*   **ลดเวลารอคอยแบบเสียเปล่า:** ไม่ต้องยืนต่อแถวหน้าบูธ สามารถรับคิวออนไลน์ ถ่ายภาพหรือเดินเล่นที่อื่นก่อนได้
*   **วางแผนการซื้อล่วงหน้า:** สามารถดูเมนูสินค้า เช็คสถานะสินค้าคงเหลือ (In-stock / Sold out) และเตรียมตัวสั่งซื้อได้ก่อนถึงคิวของตนเอง
*   **อัปเดตสถานะคิวแบบเรียลไทม์:** รู้ได้ทันทีว่าคิวถึงไหนแล้วและใกล้ถึงคิวของตนเองหรือยัง

## 3. Features (ฟีเจอร์สำหรับกลุ่ม MVP)

**ฝั่งลูกค้า (Customer Facing):**
1.  **Public Event Home (`/:slug/home`):** หน้าหลักสำหรับแสดงสถานะของบูธ (เปิด/ปิด) และข้อมูลงานอีเวนต์
2.  **Digital Catalog & Menu (`/:slug/menu`):** หน้ารายการสินค้า แสดงรูปภาพ ราคา และสถานะความพร้อมขาย รองรับการแสดงผลหลายสกุลเงิน
3.  **Online Queuing (`/:slug/queue`):** 
    *   กดรับบัตรคิวได้ทันทีผ่านระบบ 
    *   แสดงหมายเลขคิวปัจจุบันของตนเอง และหมายเลขคิวที่กำลังให้บริการอัปเดตสด (Realtime Update)

**ฝั่งเจ้าของบูธ/สตาฟ (Admin & POS):**
4.  **Event Management:** ระบบสร้างและแก้ไขข้อมูลงานอีเวนต์ เปิด-ปิดสถานะบูธ (Booth Open/Close) ได้แบบเรียลไทม์
5.  **Product Management:** 
    *   ระบบจัดการรายการสินค้า (เพิ่ม/ลบ/แก้ไข)
    *   อัปเดตสถานะการขาย (Enable, Disable, Sold Out) และรองรับการดึงข้อมูลเข้าผ่าน CSV
6.  **Queue & POS Dashboard (ระบบหลักหน้าบูธ):**
    *   **Queue Management:** การเรียกคิวถัดไป (Call Next), เปลี่ยนสถานะคิว (Waiting, Calling, Serving, Complete, Missed)
    *   **POS Checkout:** ระบบคิดเงินที่รองรับทั้งลูกค้าแบบ Walk-in และลูกค้าตามคิว 
    *   เพิ่มสินค้าลงตะกร้าสรุปยอด และบันทึกการชำระเงิน (รองรับเงินสด / โอนเงิน)
