# UI & UX Flow - EventQueueSocial
ไฟล์นี้รวบรวมภาพหน้าจอ (Screenshots) จากระบบปัจจุบัน เพื่อใช้เป็นจุดตั้งต้นในการพูดคุย ออกแบบ และวางแผนปรับปรุงประสบการณ์ผู้ใช้งานใหม่ (User Experience) และระบบอินเตอร์เฟซ (User Interface)

---

## 1. ฝั่งลูกค้า (Customer Faced Pages)

### 1.1 หน้าหลักของบูธ (Home Page)
**URL:** `/:slug/home` (เช่น `/test1/home`)
**จุดประสงค์:** แสดงข้อมูลศิลปิน สถานะบูธลิงก์โซเชียลมีเดีย
![Home Page](./home_page_1771697216580.png)

### 1.2 หน้ารายการสินค้า (Menu Page)
**URL:** `/:slug/menu` (เช่น `/test1/menu`)
**จุดประสงค์:** แสดงแคตตาล็อกสินค้า ราคา หมวดหมู่ และสถานะสต็อกในแบบเรียลไทม์ (สินค้าหมด / เหลือเท่าไหร่)
![Menu Page](./menu_page_1771697217557.png)

### 1.3 หน้าจอคิวของลูกค้า (Queue Status Page)
**URL:** `/:slug/queue` (เช่น `/test1/queue`)
**จุดประสงค์:** ให้ลูกค้าเข้ามากดรับบัตรคิว และติดตามเลขคิว ณ ปัจจุบัน (เรียลไทม์) 
*(ในรูปคือสถานะหน้าจอในกรณีที่บูธปิดรับคิว)*
![Queue Page](./queue_page_1771697218510.png)

## 2. ฝั่งเจ้าของบูธ / ทีมงาน (Admin / Staff Pages)

### 2.1 หน้าล็อกอินเข้าสู่ระบบจัดการ (Manager Login)
**URL:** `/manage-login`
**จุดประสงค์:** จุดเริ่มต้นให้ Admin หรือ Staff เข้าสู่ระบบ (เพื่อไปสู่แดชบอร์ด POS/Queue หรือ Event Manager)
![Manage Login Page](./manage_login_page_1771697218872.png)
