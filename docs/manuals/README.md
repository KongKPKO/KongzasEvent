# คู่มือ Paimon

คู่มือฉบับวันที่ 15 พฤศจิกายน 2569 ใช้ภาพจากร้านและข้อมูลจำลองใน Supabase local แยกต่างหาก ภาพหน้าจอเป็นตัวอย่าง ไม่ใช่ข้อมูลลูกค้าจริง

- `paimon-user-manual.pdf` — ร้านค้าและทีมงาน สำเนาเดียวกันอยู่ที่ `public/landing/paimon-user-manual.pdf` สำหรับลิงก์บนเว็บไซต์
- `paimon-operator-manual.pdf` — ผู้ดูแลระบบและผู้ปฏิบัติงาน
- `paimon-developer-manual.pdf` — นักพัฒนาและผู้ดูแลโค้ด
- `screenshots/` — ภาพหน้าจอที่ใช้ในเอกสาร

เมื่อแก้ข้อความ ให้แก้ `generate_user_guide.py` หรือ `generate_operations_and_developer.py` แล้วรันจาก root ของ repository เพื่อสร้าง HTML ใหม่ จากนั้นพิมพ์ HTML แต่ละฉบับเป็น PDF ขนาด A4 พร้อมตรวจจำนวนหน้า การตัดข้อความ และภาพ เมื่ออัปเดตคู่มือร้านค้าให้คัดลอก PDF เดียวกันไปยัง `public/landing/paimon-user-manual.pdf` ด้วย

ภาพและคำอธิบายอ้างอิง source ที่ตรวจในวันที่ระบุ หากระบบเปลี่ยน ให้ถ่ายภาพใหม่ด้วยข้อมูลจำลองและตรวจขั้นตอนกับหน้าจอและกฎปัจจุบันก่อนเผยแพร่
