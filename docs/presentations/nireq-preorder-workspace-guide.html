What changed

จาก “event row ที่มีปุ่มเต็มไปหมด” เป็น “workspace ของ event”

เป้าคือให้คนขายไม่ต้อง scan action 8 ปุ่มในแถวเดียว และให้ live ops, stock, pickup, dashboard อยู่ใน context ของ event นั้น.

  • 1หน้าแรกของ creator เห็น event เป็น grid พร้อมสถานะและ metric ย่อ.
  • 2กด Manage แล้วเข้า workspace ที่จัด module ตาม context เช่น prep, pre-order open, live, ended.
  • 3Live Queue และ Live POS ยังอยู่หนึ่งคลิกในช่วง booth operation.
  • 4Profile ยังเข้าถึงได้ผ่าน Creator Profile หรือ /manage-events?view=all.
Primary IA changeSlide 2
Page map

หน้าใหม่และหน้าที่ถูกต่อเข้ากัน

นี่คือ map ที่ใช้ตอนเทส. ถ้าไม่รู้จะไปไหน ให้เริ่มจาก /manage-events.

  • /manage-eventsEvent grid + profile panel. ถ้ามี active event เดียวจะ auto-open workspace ยกเว้นมี ?view=all.
  • /manage-events/:eventId/workspaceศูนย์กลางของ event นั้น: settings, catalog, pre-order, pickup, queue, POS, dashboard, history.
  • /manage-events/:eventId/preorderตั้ง selling mode, เวลาเปิด/ปิด pre-order, และ pickup instructions.
  • /:slug/menuลูกค้า browse menu. ถ้า event เป็น pre-order mode จะ checkout แบบไม่ต้องมี queue ticket.
  • /manage-events/:eventId/pickupstaff fulfillment: ค้น code, mark picked up, cancel, expire no-show.
  • /manage-events/:eventId/dashboard / historyดูยอด pre-order, order type, pickup status, และรายการย้อนหลัง.

Event workspace

Creator workflowSlide 4
Pre-order settings

เปิด pre-order ได้จากหน้า event workspace

หน้านี้เป็นจุดที่ creator ตั้งกติกาก่อนลูกค้าสั่งได้จริง.

  • 1เลือก selling mode เป็น Pre-order.
  • 2ตั้ง opens_at และ closes_at ตาม timezone ของ event.
  • 3ใส่ pickup instructions เช่น “แสดงโค้ดที่ Booth A12 เวลา 12:00-17:00”.
  • 4เช็ก readiness: มี instruction, close ก่อน event end, catalog มีสินค้าและ stock.

Staff operationsSlide 7
Stock safety

DB/RPC ถูกออกแบบให้ reserve, pickup, cancel, expire ไม่ทำ stock leak

  • create_preorder_with_stockจอง stock_reserved, กัน oversell, validate mode/window/idempotency.
  • mark_preorder_picked_upเปลี่ยน awaiting pickup เป็น picked_up และย้าย reserved เป็น sold.
  • cancel_preorder_with_stockยกเลิก order เดี่ยวและคืน reserved stock.
  • expire_preorders_for_eventปล่อย no-show หลัง event โดยไม่แตะ stock_sold.
  • get_public_order_receiptpublic read ได้เฉพาะเมื่อ order id และ pickup code match.

Accessibility and performance polishSlide 10
Manual test checklist

ลำดับที่คุณควรกดเทสด้วยมือ

  • 1Login creator แล้วเข้า /manage-events. ถ้ามี active event เดียวควรเข้า workspace อัตโนมัติ.
  • 2กลับ ?view=all แล้วเช็ก grid, profile panel, active/ended tab, และ Manage.
  • 3ใน workspace เปิด Pre-order settings: ตั้ง mode, window, instructions, save.
  • 4ไป catalog/stock แล้วมีสินค้า enabled และ stock เพียงพอ.
  • 5เปิด customer /:slug/menu, เลือก pre-order event, add item, กรอกชื่อ/contact, place pre-order.
  • 6จด pickup code แล้วเข้า pickup page. ค้น code, mark picked up, confirm.
  • 7ดู dashboard/history ว่า order type, pickup status, และยอด pre-order ถูกต้อง.
  • 8ลอง negative case: live mode ยังต้องมี queue, duplicate pickup ไม่ควรเกิด, cancel/expire คืน stock.
