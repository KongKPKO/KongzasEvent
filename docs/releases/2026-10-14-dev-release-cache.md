# DEV cache and startup improvements

DEV responses for `/manage-login` and `/sw.js` previously carried `Cache-Control: max-age=3600`; the header rule only covered `/index.html`, leaving SPA rewrite URLs stale. Hosting now revalidates documents and fixed-name release files while retaining immutable caching for hashed assets. Normal navigation uses network-first HTML; `/offline` retains its precached shell. DEV no longer registers a worker and then deletes every Cache Storage entry on load.

Additional route components load on demand. HEIC/WebP encoder files are excluded from service-worker precaching; upload tools still load when used online. A running tab checks for worker updates every five minutes while visible and on return/reconnection (checks throttled to once a minute). Controller changes display a Thai/English notice with reload/later actions; the page never reloads automatically. Save work and complete any pending action before choosing reload.

Validation: `npm run verify` passed with 99 Chromium browser cases, 24 SQL suites / 525 assertions, five stock concurrency checks and eight API smoke checks against disposable `NireqDevLocalization20261013`. The new built-app regression verifies fresh root and login navigation with an active worker, update notification without forced reload, preserved local state/cache, excluded upload encoders and offline-shell reload. Existing queue/POS, four-shop isolation and offline receipt recovery regressions also passed. Physical phone installation/backgrounding and real event-network timing remain unverified. No database changes are included.
